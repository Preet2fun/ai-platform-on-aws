# Route 53 DNS Security

Amazon Route 53 should be protected against dangling records and hijack. Remove DNS records that point to de-provisioned resources to prevent subdomain takeover. Enable query logging and use Route 53 Resolver DNS Firewall to block known-malicious domains. Protect the hosted zone with least-privilege IAM and enable DNSSEC signing for the zone.
